SQL OPERATORS:-

WHAT IS AN OPERATOR:-
---
OPERATOR IS A SYMBOL IT PERFORMS SPECIFIC TASK.

SYNTAX:- OPERAND OPERATOR OPERAND
          a         +       b    

---->TYPES OF OPERATORS:-

1.ARITHEMETIC OPERATORS

---- (+,-,*,/,
2.COMPARISION OPERATOR

<,>,<=,>=

3.LOGICAL OPERATOR

--- LOGICAL AND
IF BOTH ARE TRUE RETURN TRUE
--- LOGICAL OR
IF BOTH ARE FALSE RETURN FALSE
--- LOGICAL NOT
