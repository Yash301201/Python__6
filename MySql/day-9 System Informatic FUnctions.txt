System information Functions:
Aggregate Functions(): Only applicable to numeric data types but no other data types. 
There are total five function :
-----------------------
1.count()
2.min()
3.max()
4.avg()
5.sum()

Clauses:
In mysql clauses are used to control how data is filtered, grouped, sorted, or modified in SQL quereies,
where clause:
--------------
Filtered records based on specified conditions where clause can be used as  comparision operators, logical operators and etc...... operators.
syntax:
--------
select column1,column2.... from table where condition;

group by clause:
------------------
The group by clause is used to group the rows having the same values in one or column more columns is commonly used with aggregate functions such count(). min(), max(), sum(), avg().
syntax:
----------
select column_name, aggregate_function(column_name) from table_name group By column_name;

Having clause:
===============
The having clause is used to filter grouped records after group by clause. It is similar where but it works on grouped instead of individual rows.

syntax:
---------
select column_name, agrreate_function(column_name) from table_name group by column_name having conditions;

order by clause:
================
the order by clause is used to sort the result set in ascending (ASC) or descending
Here (ASC)  is optional to put or not 
syntax:
========
select column_name from table_name order by column-name;

Execution order of clause:
===========================
1.From
2.Where
3.Group by
4.Having
5.Select 
6.Order by
