Numeric Functions:
------------------
abs(): absolute value of a number

ceil(): round up

floor(): round to a specific number of digits.

mod(): modulo of number

pow()/power(): exponential

sqrt():square root

exp(): exponential

radians(): convert degree to radians

degrees(): convert radians to degree

sign(): return the sign of a number

rand(): generate a random number

greatest(): find the maximum value

least(): find minimum value

pi(): return the value pi(3.14)

hex(): convert to hexadecimal

oct(): convert to octal

bin(): convert to binary.
