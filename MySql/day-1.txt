what is data? 
Raw facts or figures without context
example: 101,Yash,50000, VSP

what is field?
Field/attribute is column name of the table (smallest unit of data in database)
example: emp_name, emp_salary, emp_id

what is record?
Collections of related fields (row/tuple)
example:(101,'sunny',50000)

what is database?
Organized collection of related records stored together
example: an employee DB containing all employee records.  

Client-Server architecture:
------------------------------

Client: The role of the client in client server architecture is to send request to the server and to get response from the server.

Server: Server is a software, the role o the server in client-server-architecture is to take request from  the clients. If the request is valid request it will generate and we cam handover that response to client. If the client request is not a valid request it will raise some error status codes. 

Protocol: It has a set of rules and regulations. The role of the protocol in client-server-architecture is to send request from client to server.

Structured Query language(SQL): 
SQL Commands: It is a Structured Query language. It is standardized programming language specifically designed for managing and manipulating relational DB. It provides a declare syntax that allows users to define what data they want to retrieve, insert, update, or delete, without specifying exactly how DB should execute these operations.

(databases are unique and do not create existing database name or table name)

Drop:
1.removes the table or object.
2.table structure + data
3. table structure will also remove.
4.performance is slow (due to full removal)
Delete :
1.removes specific rows from a table specific rows(based on condition)
2.table structure intact.
truncate:
1.remove all rows, keeps the table structure all rows
2.table structure intact 
3.performance is fast(bulk deletion)
