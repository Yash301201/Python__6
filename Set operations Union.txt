Set operations:
-----------------
Union: Combine results from two queries and removes duplicate rows columns must have the same number and type.
Union All: combines results from 2 queries and include all rows including duplicats must have the same number and type.
Intersect: Returns rows that are common to both queries.(Mysql does not support intersect directly)
Minus/Except: Returns rows from the first query that are not present in the second query. Columns must have the same number and type.

Joins:
------
An joins in mysql is used to combined rows from two or more tables based on related columns.

example:
employee_table: emp_details
department--> dept_details

if you want to see which employee belongings tp which department. you need to join these two tables.
Why do you need joins?
--------------------------
To fetch data from multiple tables in a single query.
To reduce data duplications (instead of keping everything in one table)
To implement relations like(one-to-one,one-to-many,many-to-many,many-to-one)
TO generate reports and analytics combining different dataset.

Types of Joins:
================
Inner Join: Return only rows that have matching values in both tables.
syntax : 
select columns
from table
inner join table2
on tabel1.common_column = table2.common_column;

Left join: returns all rows from the left table and matched from the right table if no match null values appear for the right table columns.
syntax:
select columns
from table
left join table2
on tabel1.common_column = table2.common_column;

right join : returns all rows from the right table and matched from the left table if no match null values appear for the left table columns.
syntax:
select columns
from table
right join table2
on tabel1.common_column = table2.common_column;

full join: to simulate the used the union of left join and right join.
syntax:
select columns
from table
left join table2
on tabel1.common_column = table2.common_column
union
select columns
from table
right join table2
on tabel1.common_column = table2.common_column;

cross join: returns partitions products --> every row from the first table with every row from the second table.
syntax:
select columns
from table 
cross join table2;
self join: a table joined with itself,
select a.column,b.columns
from table1 a 
inner join table1 b
on a.common_column=b.common_column;
